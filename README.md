## 📦 Project Overview

**Pocket Friends** is a 2D pet care simulation game created as part of the Girls Who Code mentor project series.  
Players interact with a clean, intuitive Pygame interface to browse store items, check hunger/happiness levels, and simulate simple feeding and cleaning mechanics.

This project is designed to help new programmers understand the fundamentals of game development in Python through practical, hands-on examples.

---

## 🎯 What the Project Does

Pocket Friends includes:

- A fully interactive **shop UI**
- Clickable item cards with icons  
- Hover highlights and UI animations  
- A simple **inventory system**   
- Cleanly organized code for easy modification  

It teaches key Pygame concepts:

- Game loops  
- Surface rendering  
- Sprite loading & scaling  
- Collision detection  
- State management  
- UI layout logic

## Getting Started 
### 🔧 Requirements
- **Python 3.10+** 
- **Pygame** → install via:
```bash
pip install pygame
```

## Launching the game 
Once you have everything installed, navigate to the project folder, and you can launch the game through `game.py`.
```bash
python game.py
```
